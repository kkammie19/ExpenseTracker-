# ExpenseTracker2

## Description

ExpenseTracker2 is a simple Android application for tracking personal expenses.

The application helps users record their expenses and keep track of their spending in one place.

## Features

* Add new expenses
* View a list of expenses
* Track spending
* Simple and user-friendly interface

## Technologies

* Kotlin
* Android Studio
* Android SDK
* Gradle

## Project Structure

The main application code is located in the `app` folder.

## How to Run

1. Clone or download the project from GitHub.
2. Open the project in Android Studio.
3. Wait for Gradle Sync to finish.
4. Connect an Android device or start an Android Emulator.
5. Click **Run** to launch the application.
